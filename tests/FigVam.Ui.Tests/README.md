# Запуск UI-тестов FigVam

Из корня репозитория (PowerShell):

```powershell
./run-ui-tests.ps1 -Setup                 # Сборка сервера, npm ci, установка Chromium
./run-ui-tests.ps1 -List                  # Все тесты и их постоянные номера
./run-ui-tests.ps1 -Test 1                # Обычный прогон login-flow
./run-ui-tests.ps1 -Test 1 -Headed        # С видимым браузером
./run-ui-tests.ps1 -Test 1 -Demo          # Видимый браузер, пояснения и замедление
./run-ui-tests.ps1 -Test 1 -Demo -SlowMo 700 -StepDelay 2000
./run-ui-tests.ps1 -Test login-flow -Debug
./run-ui-tests.ps1 -Test all              # Все UI-тесты
```

Скрипт работает из любого текущего каталога и сам переходит в каталог UI-тестов.
`-Setup` достаточно выполнить один раз после установки .NET SDK и Node.js, а затем повторять после обновления зависимостей или сборки.
Тесты автоматически запускают изолированный локальный сервер FigVam с отдельным хранилищем; вручную запускать Aspire не нужно.

Режим `-Demo` подразумевает `-Headed`, замедление действий Playwright на 500 мс и паузу 2000 мс после каждого подписанного этапа.
`-SlowMo` и `-StepDelay` задаются в миллисекундах и могут быть переопределены, включая значение `0`.

Подписи к этапам определены непосредственно в `login-flow.spec.js` через `demo.step(...)`.
Их отображение реализовано в `demo-overlay.js`; панель находится поверх страницы, не перехватывает клики и не меняет код приложения.
В стандартных тестах и CI панель и паузы отключены.

Номера тестов зафиксированы в `run-ui-tests.ps1`. Для нового теста нужно добавить запись с новым номером, не перенумеровывая старые.
