# IDD-0002.spec-portability

Версионированный Portable UI Profile определяет допустимые типы узлов, свойства, значения, события и связи. Для каждого узла известны семантическая роль и правила компоновки, а для каждого свойства — отображение на целевые платформы, включая интерактивный просмотр. Цели V1 — HTML/CSS, WPF/XAML, Avalonia/XAML и Uno Platform/XAML. Конструкция допускается только при определённой и проверенной семантике на каждой цели объявленного профиля. Неподдерживаемые значения не предлагаются инспектором и отвергаются сервером с ID объекта, свойством и причиной, включая платформенное ограничение. Диагностика экспорта также указывает способ исправления.

Экспорт не теряет семантику молча, не заменяет интерактивный элемент изображением и не подменяет его тип незаметно. Допустима явно определённая декларативная композиция стандартных примитивов, если результат читаем и редактируем. Платформа объявляется поддерживаемой только после проверок соответствия. Новые возможности профиля требуют документированного отображения и автоматических проверок на всех четырёх целях; обычное обновление не должно неожиданно инвалидировать существующие документы.

Логическая единица uiUnit в базовом масштабе равна CSS px и WPF DIP (1/96 дюйма); масштаб редактора не изменяет документ, экспортёр не применяет неявное масштабирование структуры. Гарантируются эквивалентные структура, компоновка и поведение с документированными допусками геометрии, шрифтов и графики, а не попиксельная идентичность. Проверяются доступность шрифтов, fallback, переполнение и отсутствие накопления ошибок округления. Сопоставляются структура элементов и доступности, интерактивные роли, размеры, выравнивание, порядок, видимость, переполнение и цвета в Preview и каждой цели при фиксированных шрифтах, разрешениях и темах. Pixel diff — дополнительная метрика. Открытые вопросы профиля: IDD-0014.
