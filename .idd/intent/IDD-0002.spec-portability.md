# IDD-0002.spec-portability

Версионированный Portable UI Profile определяет допустимые типы узлов, свойства, значения, события и связи. Для каждого узла известны семантическая роль и правила компоновки, а для каждого свойства — отображение на целевые платформы, включая интерактивный просмотр. Цели V1 — HTML/CSS, WPF/XAML, Avalonia/XAML и Uno Platform/XAML. Каждая версия профиля явно объявляет поддерживаемые целевые платформы. Конструкция допускается только при определённой и проверенной семантике на каждой из платформ, объявленных этой версией. Для MVP допустим профиль только для HTML/CSS и браузерного Preview; WPF, Avalonia и Uno добавляются лишь после проверок. V1 предусматривает проверенный профиль всех четырёх целевых платформ. Неподдерживаемая платформа не предлагается как доступный экспорт. Неподдерживаемые значения не предлагаются инспектором и отвергаются сервером с ID объекта, свойством и причиной, включая платформенное ограничение. Диагностика экспорта также указывает способ исправления.

Экспорт не теряет семантику молча, не заменяет интерактивный элемент изображением и не подменяет его тип незаметно. Допустима явно определённая декларативная композиция стандартных примитивов, если результат читаем и редактируем. Платформа объявляется поддерживаемой только после проверок соответствия. Новые возможности профиля требуют документированного отображения и автоматических проверок на всех объявленных платформах текущей версии. Изменение набора возможностей, правил или их семантики требует новой версии профиля. Существующие документы сохраняют однозначную интерпретацию версии, с которой они созданы; обычное обновление не должно неожиданно инвалидировать или молча переинтерпретировать существующие документы. Палитра, инспектор, серверная валидация, Preview и экспорт используют один согласованный реестр профиля, без обхода валидации.

Логическая единица uiUnit в базовом масштабе равна CSS px и WPF DIP (1/96 дюйма); масштаб редактора не изменяет документ, экспортёр не применяет неявное масштабирование структуры. Гарантируются эквивалентные структура, компоновка и поведение с документированными допусками геометрии, шрифтов и графики, а не попиксельная идентичность. Проверяются доступность шрифтов, fallback, переполнение и отсутствие накопления ошибок округления. Сопоставляются структура элементов и доступности, интерактивные роли, размеры, выравнивание, порядок, видимость, переполнение и цвета в Preview и каждой цели при фиксированных шрифтах, разрешениях и темах. Pixel diff — дополнительная метрика. Открытые вопросы профиля: IDD-0014.
