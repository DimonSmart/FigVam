# IDD-0011.spec-export

Платформенный экспорт является необязательным будущим направлением и не входит в критерий текущей версии. При его реализации экспорт принимает неизменяемый снимок документа определённой ревизии, профиль, область Screen/Component/Document и параметры. Результат включает исходники, manifest, список сгенерированных ассетов и отчёт соответствия. Перед генерацией проверяются документ и все свойства профиля; ошибка сообщает ID узла, свойство, причину и способ исправления без тихого fallback. Экспортёр сопоставляет семантические имена с идентификаторами целевой платформы. Одинаковые вход и версия экспортёра дают эквивалентные файлы.

Генерация сохраняет читаемую декларативную структуру, layout, размеры, ограничения, тексты, тему, ассеты и, где возможно, переиспользуемые компоненты. Токены отображаются в CSS variables или XAML resources/styles. HTML использует семантические элементы; WPF, Avalonia и Uno — соответствующий компилируемый XAML. Не допускается сплющивание интерфейса в изображение или абсолютные координаты без причины. Возможны binding contracts и заглушки обработчиков; генерация не обещает рабочую бизнес-логику. Неэкспортируемые сценарии явно документируются, статическое состояние соответствует дизайну.

При заявлении поддержки платформы её адаптер должен быть проверен, включая отсутствие скрытой растеризации UI и диагностику отсутствующих ассетов. Неготовая цель не рекламируется как поддерживаемая. Текст может иметь локализационный ключ, fallback и типизированную связь с текстовым каталогом; Preview допускает временные подстановки и псевдолокализацию с увеличением длины, маркерами и диакритикой для выявления обрезания и переполнения. Локализация инструмента отделена от локализации дизайна.
