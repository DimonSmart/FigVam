# ENG-0004.rule-command-journal

## Rule

Все мутации модели проводить через общий типизированный обработчик доменных команд. Для каждого документа обеспечить одного логического владельца и последовательное исполнение; независимая запись нескольких серверных экземпляров в раздельное состояние одного документа запрещена. Надёжно фиксировать принятые команды в транзакционном журнале до ACK, использовать периодические неизменяемые снимки для восстановления, отделяя их от именованных пользовательских версий.

## Applicability

Conditional

## Applies when

Реализация или изменение обработки команд, совместной работы и хранения документа.
