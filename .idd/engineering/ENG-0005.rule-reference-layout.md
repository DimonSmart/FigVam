# ENG-0005.rule-reference-layout

## Rule

Вычислять эталонную геометрию тестируемым чистым доменным движком компоновки; использовать общие правила для диагностики Preview и проверки экспорта. Локальный предварительный показ жестов допустим, но не меняет семантику результата.

## Applicability

Conditional

## Applies when

Реализация или изменение компоновки, предпросмотра и проверки экспорта.
