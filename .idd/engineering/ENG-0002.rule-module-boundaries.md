# ENG-0002.rule-module-boundaries

## Rule

Доменная модель и её инварианты не зависят от HTTP, SignalR или базы данных; выбор физического хранилища не проникает в домен. Application отвечает за команды, запросы, права, транзакции и версии, а не за вёрстку SPA. Transport API не содержит доменных правил. Storage не интерпретирует layout, Layout не обрабатывает события браузера, Export не изменяет документ. Запросы, команды, экспорт, рендеринг прототипа и проверка профиля доступны через внутренние интерфейсы; будущий MCP адаптирует их, не создавая собственную модель редактирования.

## Applicability

Always
