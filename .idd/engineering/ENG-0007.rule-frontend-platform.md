# ENG-0007.rule-frontend-platform

## Rule

Поддерживаемый исходный код интерфейса FigVam реализуется на TypeScript со строгими проверками, включая noImplicitAny, strictNullChecks и noUncheckedIndexedAccess; ошибки типов не обходятся массовыми any, отключением проверок или необоснованными приведениями. Декларативный интерфейс приложения строится на React, собирается Vite, стандартные контролы переиспользуют Base UI, стандартные иконки — Lucide React. Зависимости фиксируются lock-файлом и добавляются по обоснованной необходимости.

HTTP-контракты выводятся из серверной OpenAPI-спецификации, а недостаточно полные контракты дополняются типизированными адаптерами без изменения семантики сервера. Транспорт, команды, ревизии, авторизация и совместное редактирование имеют явных владельцев и сохраняют действующие гарантии. Графический движок не зависит от React; React не управляет DOM-поддеревом движка. UI Kit приложения и отображение пользовательских документов не смешиваются; компоненты не дублируют доменные правила backend.

Рукописные исполняемые frontend-модули не размещаются в wwwroot: там находятся статическая разметка и стили, а JavaScript генерируется сборкой. Обычные панели не создают собственные React roots или параллельные legacy-реализации; временный адаптер порталов используется только для завершения миграции существующего shell. Переиспользуемые контролы документируются в UI-KIT.md. Специализированные контролы и canvas допускают собственную реализацию с явной границей владения DOM и освобождением ресурсов.

## Applicability

Conditional

## Applies when

Создание, изменение или сопровождение frontend-приложения FigVam, его компонентов, клиентских контрактов и графического движка.

## Verification

Строгая проверка TypeScript, воспроизводимые сборка и генерация API-типов, модульные тесты критичной логики и существующие регрессионные сценарии. Сгенерированные frontend-ресурсы публикуются с ASP.NET без отдельного Node.js сервера.
