# ENG-0001.rule-server-platform

## Rule

Реализовывать backend на C# и поддерживаемом .NET LTS с ASP.NET Core. Использовать Aspire для локальной оркестрации, конфигурации и наблюдаемости. Начальная архитектура — модульный монолит в одном процессе; разделение на сетевые сервисы допускается при доказанной эксплуатационной необходимости.

## Applicability

Always
